# CellPresence
CellPresence is a simple way to get your PS3 games onto Discord as rich presence.

# Features
- **Easy to use.** CellPresence has a GUI, and it runs in the background, and never gets in your way.
- **It's stupid fast.** Written in Rust, CellPresence is blazing fast, uses barely any RAM, and is still intuitive to use! 

# Usage
Using CellPresence is insanely easy! There's only 3 steps. Make sure you have CFW or HEN, and [webMAN MOD](https://github.com/aldostools/webMAN-MOD) installed.

1. **Open CellPresence.**
2. **Set up your discord app ID at the Discord Developer Portal.**
3. **Choose your PS3 from the list of IP addresses.** These are local IP's and are never sent. 

That's it. No extra fluff.
